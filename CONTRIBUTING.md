# Contributing

This tutorial is designed to grow through practical system design examples.

Good contributions include:

- New mobile system design examples.
- Better requirement checklists.
- Android-specific architecture tradeoffs.
- Diagrams that clarify data flow or ownership.
- Interview answer walkthroughs.
- Corrections that improve technical accuracy.

When adding examples, prefer this structure:

1. Scope.
2. Functional requirements.
3. Non-functional requirements.
4. High-level architecture.
5. Mobile client architecture.
6. Data model and APIs.
7. Offline/sync behavior.
8. Failure modes.
9. Security/privacy.
10. Observability and rollout.
11. Tradeoffs.

Keep examples practical and explicit. The goal is to teach judgment, not to collect buzzwords.
